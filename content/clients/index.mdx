# 客户端接入

几乎所有支持 **OpenAI 兼容** 或 **Anthropic 兼容** 的客户端都能接入 OpenApi。无论用哪个客户端,你只需要准备两样东西。

## 你需要准备的两样东西

1. **Base URL(接口地址)**,按网络环境二选一:

   | 线路 | Base URL |
   | --- | --- |
   | 主线路 · 大陆 CDN | `https://api.openrealm.cn/v1` |
   | Global · 纯 API 加速 | `https://global.api.openrealm.cn/v1` |
   | Global EdgeOne 线路 | `https://api.openapi.edgeone.gloabl.muhan.wiki/v1` |

2. **API Key**:登录控制台 [api.openrealm.cn](https://api.openrealm.cn),在「令牌 / Token」页创建,形如 `sk-...`。

<Callout type="warning">
  API Key 等同于账户余额,不要写进前端代码或提交到 Git 仓库。给客户端使用时,建议单独创建一个额度受限的令牌。
</Callout>

## 一个关键区别:带不带 `/v1`

不同客户端对地址的要求不一样,这是接入时最常见的坑:

- **OpenAI 兼容客户端**(Cherry Studio、ChatBox、LobeChat 等):地址通常填到 **带 `/v1`**,即 `https://api.openrealm.cn/v1`。
- **Anthropic / Claude Code**:地址填到**站点根**(**不带 `/v1`**),即 `https://api.openrealm.cn`,客户端会自行拼接 `/v1/messages`。

<Callout type="info">
  拿不准时,先用 [在线调试](/playground) 确认你的 Key 和线路能正常返回,再去配置客户端,能少走很多弯路。
</Callout>
