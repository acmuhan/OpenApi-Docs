# 模型

下面展示当前可调用的模型、各自支持的协议(OpenAI / Anthropic / Gemini)与所属分组。点击模型名可复制,填入请求的 `model` 字段即可。

## 查询「我的可用模型」

上面是**全站模型目录**。而不同 Key 因所属**分组**不同,实际能调用的模型也不同。填入你的 Key,即可查询**这把 Key 真正可用**的模型列表(直接调用 OpenAI 标准的 `/v1/models`)。
